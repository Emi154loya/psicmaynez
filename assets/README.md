# Carpeta de recursos (`assets/`)

Para mostrar la fotografía profesional de la Lic. Grecia Pamela Máynez en el Hero:

1. Coloca tu imagen en esta carpeta con el nombre exacto:
   `grecia-perfil.jpg`
2. Formato recomendado:
   - Orientación vertical (proporción `4:5`, por ejemplo `800 × 1000 px` o `960 × 1200 px`).
   - Peso optimizado menor a `250 KB` en formato `.jpg` (o calidad 80–85%).
   - Iluminación cálida natural, encuadre centrado superior (`object-top` ya está configurado para cuidar el rostro).

Mientras el archivo `grecia-perfil.jpg` no exista en esta carpeta, la página mostrará automáticamente un marco editorial limpio y sin íconos de imagen rota.
